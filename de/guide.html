Revivetendo Relais Netzwerk — Setup Guide

Wählen Sie Ihre Konsole aus, um mit dem Revivetendo Relay Network loszulegen.

Installationsschritte

Folgen Sie diesen vier Schritten, um Ihre Konsole mit dem Server zu verbinden.

Schritt 1

Überprüfe dein Homebrew Setup

Ihre Wii U muss die Aroma Homebrew Environment mit Coldboot aktiviert sein.

Warum Coldboot benötigt wird

Coldboot startet Inkay, wenn die Konsole eingeschaltet ist, damit SpotPass Dienste sich richtig verbinden können. Ältere Methoden wie Tiramisu oder Haxchi werden nicht unterstützt.

Voraussetzungen

  • Wii U läuft Aroma mit Coldboot aktiviert.
  • SD-Kartenleser oder FTP-Verbindung zu Ihrer Konsole.
  • Pretendo Netzwerk ID (PNID).
Schritt 2

Download Inkay Switcher

Laden Sie die Inkay Switcher Anwendung herunter, um zwischen Serverrelais auf Ihrer Konsole zu wechseln.

Inkay Switcher (.wuhb)

Wii U Aroma-Anwendung

Download Release (.wuhb)
Lade revivetendo_installer.wuhb aus dem Abschnitt Assets auf GitHub herunter.

SD-Kartenplatzierung

Kopieren Sie revivetendo_installer.wuhb in das /wiiu/apps/ Verzeichnis auf Ihrer SD-Karte:

Verzeichnispfad kopieren 
sd:/wiiu/apps/revivetendo_installer.wuhb

Wenn du die SD-Karte zurücklegt und die Wii U startest, wird das Revivetendo Installer Symbol auf deinem HOME Menü angezeigt.

Revivetendo Installer Programm Kachel (Rv Installer) auf Ihrem Wii U HOME Menü.
Schritt 3

Benutzerdefiniertes Relais installieren

Konfigurieren Sie Ihre Konsole so, dass Wii U Chat auf Nicos Server geleitet wird.

  1. Öffne Inkay Switcher: Starte Revivetendo Installer aus deinem Wii U HOME Menü.
  2. Benutzerdefiniertes Relais wählen: Wählen Sie Revivetendo. (Um später zum Standard Pretendo zurückzukehren, wählen Sie stattdessen Pretendo aus).
    Wähle "Revivetendo" aus dem Schaltmenü aus.
  3. Installieren und Neustarten: Wählen Sie Ihre Umgebung aus, drücken Sie A um zu installieren, dann drücken Sie B um neu zu starten.
    Bestätigungs-Eingabeaufforderung vor dem Neustart angezeigt.

Überprüfungsprüfung

Überprüfen Sie nach dem Neustart den linken oberen Banner im HOME-Menü. Es sollte heißen: Benutze Pretendo Netzwerk (Revivetendo).

In-Game Plugin Menü

Öffnen Sie das Plugin-Menü überall auf Ihrer Wii U durch Drücken von L + + - oder +. Wählen Sie Inkay (Revivetendo) aus, um die Verbindungseinstellungen zu verwalten oder Ihre WaraWara Plaza zurückzusetzen.

Juxtaposition Miiverse

Voraussetzungen

  • Ein homebrew-fähiger 3DS (echte Hardware) oder Azahar.
  • Ein CIA-Installer auf echter Hardware, wenn Sie noch keinen haben (FBI ist die Standardwahl).
  • Die neueste Nimbus App Release (nimbus.cia, tag app-v*) von nimbus-nico_christmann veröffentlicht. Verwenden Sie diesen und nicht den Upstream: Die Patches werden automatisch von der App heruntergeladen.
  • Eine funktionierende Internetverbindung auf der Konsole.
  • Nur für Azahar: die Azahar URL Weiterleitung Datei Release (http_hle_replace_rules.txt) von der gleichen Release-Seite.

Installationsschritte: Echte Hardware

Folge diesen Schritten, um deinen physikalischen 3DS/2DS mit dem Server zu verbinden.

Schritt 1

Nimbus installieren

Lade nimbus.cia von der neuesten app-v* Version herunter und lege sie auf deine SD-Karte. Installieren Sie FBI (oder Ihren CIA-Installer der Wahl), wenn Sie FBI verwenden.

Schritt 2

Benutzerdefiniertes Relais auswählen

Öffne den Nimbus vom Home-Menü und drücke SELECT , um den Netzwerkbildschirm zu öffnen.

Wählen Sie Revivetendo mit den UP/DOWN Buttons und drücken Sie A. Nimbus lädt die neuesten Patches herunter, installiert sie und bittet Sie, zum Neustart zu drücken.

Netzwerkbildschirm-Optionen

  • Pretendo — das Material Pretendo Patches.
  • Roseverse — Pretendo mit Roseverse's Account, HTTP und Miverse Patches.
  • Revivetendo — unser komplettes Netzwerk. Ersetzt alles inklusive eShop/Badge Arcade Patches, die nur hier vorhanden sind, und leitet das, was wir Hosting an uns und alles andere an Pretendo weiter.
Schritt 3

Miiverse testen

Öffnen Sie Miiverse aus Ihrem Home-Menü zum Test. Wenn es erfolgreich geladen wird, bist du gut zu gehen! Echte Hardware holt die Umleitungen automatisch ab, sobald Nimbus gepatcht wird.

Installationsschritte: Azahar (Emulator)

Azahars emulierte SD-Karte ist der Ordner sdmc in Ihrem ausgewählten Azahar Speicherordner.

Schritt 1

Nimbus installieren

Laden Sie nimbus.cia von der neuesten app-v* Version herunter. In Azahar installieren Sie es genauso wie jede CIA (File → CIA installieren).

Schritt 2

LLE Module aktivieren

Aktivieren Sie die Option "Aktivieren Sie die benötigten LLE-Module, um Online-Dienste zu nutzen" in Azahar (mulation → Konfigurieren → System). Andernfalls werden Online-Funktionen nicht funktionieren.

Schritt 3

Patches in Nimbus anwenden

Starte das Home-Menü, führe Nimbus aus, drücke SELECT, wähle Revivetendo und wende die Patches genau wie auf realer Hardware an.

Schritt 4

URL-Weiterleitung einrichten

Laden Sie http_hle_replace_rules.txt von der Azahar URL Weiterleitung Datei herunter und platzieren Sie sie auf:

<your Azahar storage folder>/sysdata/http_hle_replace_rules.txt

Es muss keine Emulator-Einstellung eingeschaltet werden. Azahar lädt diese Datei beim nächsten Start automatisch.

Schritt 5

Test und Verifizieren

Zum Testen Miiverse starten. Sie können Azahars Protokolldatei auf eine Zeile überprüfen wie:

Service.HTTP <Warning>... Anwenden:2258: Regel "<pattern>" hat URL "<original>" nach "<new> " ersetzt

Wenn Sie das mit einem sinnvollen Ersatz sehen, wird die Umleitung leben.

Was wird umgeleitet?

Beide Pfade leiten den gleichen Satz von echten Nintendo/Pretendo Hostnamen auf unseren eigenen Server um:

  • Miiverse
  • BOSS/SpotPass
  • conntest & Account Login
  • Swap Doodle's NASC login + HPP relay
  • Nintendo Badge Arcade's eShop-Style "buy plays" flow (verwies auf unser eigenes Shop-Backend anstelle von Nintendos echten Servern).

Hinweis: 3DS Freunde und NASC für andere Titel bleiben bewusst übrig und zeigen auf das echte Pretendo Network, unverändert.
