Revivetendo Relay Network — Руководство по установке

Выберите консоль, чтобы начать работу с Revivetendo Relay Network.

Шаги установки

Выполните эти четыре шага, чтобы подключить консоль к ретранслятору.

Шаг 1

Проверьте настройки Homebrew

Ваш Wii U должен быть запущен Aroma Homebrew Environment с включенным Coldboot.

Почему Coldboot необходим

Coldboot запускается Inkay при включенной консоли, чтобы службы SpotPass могли подключаться должным образом. Старые методы, такие как Tiramisu или Haxchi, не поддерживаются.

Предпосылки

  • Wii U запущен Aroma с включенным Coldboot.
  • Соединение с вашей консолью с картами SD или FTP.
  • Pretendo Network ID (PNID).
Шаг2

Скачать Inkay Switcher

Скачайте приложение Inkay Switcher, чтобы переключаться между ретрансляторами сервера на вашей консоли.

Inkay Switcher (.wuhb)

Приложение Wii U Aroma

Скачать релиз (.wuhb)
Скачать revivetendo_installer.wuhb из раздела Активов на GitHub.

Размещение SD-карты

Скопируйте revivetendo_installer.wuhb в папку /wiiu/apps/ на SD-карте:

Путь к каталогу 
sd:/wiiu/apps/revivetendo_installer.wuhb

Когда вы вернете SD-карту и запустите Wii U, значок Revivetendo Installer появится в меню HOME.

Revivetendo Installer плитка приложения (Rv Installer) в меню Wii U HOME.
Шаг3

Установить пользовательский передатчик

Настройте консоль на маршрут Wii U Chat на сервер Nico.

  1. Open Inkay Switcher: Запустите Revivetendo Installer из вашего меню Wii U HOME.
  2. Выберите пользовательский передат: Выберите Revivetendo. (Чтобы позже вернуться к стандартной версии Pretendo выберите Pretendo.
    Выберите "Revivetendo" из меню переключателя.
  3. Install and Reboot: Select your environment, press A to install, then press B to reboot.
    Confirmation prompt shown before rebooting.

Проверка верификации

После перезагрузки проверьте верхний левый баннер в меню HOME. Он должен говорить: Использование Pretendo сети (Revivetendo).

В игровом меню плагина

Откройте меню плагинов в любом месте на вашей Wii U, нажав L + + - или +. Выберите Inkay (Revivetendo) для управления настройками подключения или сбросите ваш WaraWara Plaza.

Миверс Juxtaposition

Шаги установки: реальное оборудование

Выполните следующие шаги для подключения вашей физической 3DS/2DS к ретранслятору.

Шаг 1

Установить Nimbus

Загрузите nimbus.cia из последнего релиза app-v* и поместите его на SD-карту. Используя FBI (или ваш установщик CIA), установите его.

Шаг2

Выберите пользовательский передатчик

Откройте Nimbus из главного меню и нажмите ВЫБЕРИТЕ для открытия сетевого экрана.

Choose Revivetendo with the UP/DOWN buttons and press A. Nimbus загрузит новейшие заплатки, установит их и попросите нажать Start для перезагрузки.

Параметры сетевого экрана

  • Pretendo — патчи на складе.
  • Roseverse — Pretendo с заплатками Roseverse, HTTP и Miiverse .
  • Revivetendo — полная наша сеть. Заменяет на место все, включая только существующие здесь заплатки в eShop/Badge Arcade, маршрутизируя то, что мы принимаем к нам и все остальное для Pretendo.
Шаг3

Тест мивера

Откройте Miiverse из главного меню для тестирования. Если она загружена успешно, вы хорошо поймете! Реальное аппаратное обеспечение подбирает редиректы автоматически после того, как Nimbus патча.

Шаги установки: Azahar (Эмулятор)

Azahar's emulated SD card is the sdmc folder inside your selected Azahar storage folder.

Шаг 1

Установить Nimbus

Download nimbus.cia from the latest app-v* release. В Azahar, установите его так же, как и любой CIA (Файл → Установить CIA).

Шаг2

Включить LLE модули

Enable the "Enable required LLE modules to use online services" option in Azahar (Emulation → Configure → System). Без этого онлайн функции не будут работать.

Шаг3

Применить патчи в Nimbus

Загрузите Главное меню, запустите Nimbus, нажмите SELECT, выберите Revivetendo и примените патчи, как на реальной аппаратной программе.

Шаг4

Установка URL перенаправления

Скачайте http_hle_replace_rules.txt из релиза Azahar URL Redirection File и разместите его в:

<your Azahar storage folder>/sysdata/http_hle_replace_rules.txt

Не нужно переключать настройки эмулятора. Azahar загружает этот файл автоматически при следующем запуске.

Шаг5

Тест и проверка

Запустите Miiverse для тестирования. Вы можете проверить лог-файл Azaharа на следующую строку:

Service.HTTP <Warning>... Apply:2258: rule "<pattern>" has replaced URL "<original>" to "<new>"

Если вы видите, что с разумной заменой редирект жив.

Что перенаправляется?

Оба пути перенаправляют один и тот же набор реальных имен хостов Nintendo/Pretendo на наши собственные серверы:

  • Миверс
  • BOSS/SpotPass
  • конкурс и логин аккаунта
  • Swap Doodle's NASC login + HPP relay
  • Nintendo Badge Arcade's eShop-style "купить плей" поток (отметил в нашем собственном бэкэнде магазин вместо реальных серверов Nintendo).

Note: 3DS Friends and NASC for other titles are deliberately left pointing at the real Pretendo Network, untouched.
