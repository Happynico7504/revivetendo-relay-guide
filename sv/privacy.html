Integritetspolicy

Information om de data vi behandlar och lagrar på Revivetendo Relay Network.

Hur Revivetendo ansluter

Precis som officiella servrar måste vårt nätverk verifiera din konsol för att låta dig spela online. När du ansluter skickar konsolen automatiskt sitt serienummer, enhets-ID/certifikatoch ett lösenord hash för att logga in.

Varför skickar min konsol detta?

Denna information är strikt teknisk och används endast för att få din anslutning att fungera! Eftersom Revivetendo Relay Network tillåter din homebrewed-konsol att ansluta till anpassade tjänster, vi måste autentisera din enhet på exakt samma sätt som de officiella servrarna gör. Det hjälper oss att hålla nätverket säkert och stabilt för alla.

Vad exakt behövs för att logga in?

  • Konsolserienummer: Hjälper nätverket att känna igen din specifika konsol när du ansluter.
  • Enhets-ID / Certifikat: Ett standardkrav för säker kommunikation så att konsolen säkert kan prata med nätverket.
  • Lösenord Hash: Används för att logga in på ett säkert sätt. Din konsol kodar automatiskt ditt lösenord till en säker "hash" innan du ansluter, så att ditt faktiska lösenord aldrig lämnar din konsol.

Är mina data säkra?

Absolut! Denna tekniska data säljs eller delas aldrig. Det finns helt enkelt för att hålla din konsol säkert inloggad och se till att nätverket hålls igång för alla.
