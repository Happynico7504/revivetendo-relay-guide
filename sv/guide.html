Revivetendo Relay Network — Setup Guide

Välj konsolen för att komma igång med Revivetendo Relay Network.

Installationssteg

Följ dessa fyra steg för att ansluta konsolen till reläet.

Steg 1

Kontrollera din Homebrew Setup

Din Wii U måste köra Aroma Homebrew Environment med Coldboot aktiverad.

Varför Coldboot krävs

Coldboot startar Inkay när konsolens befogenheter på så att SpotPass tjänster kan ansluta ordentligt. Äldre metoder som Tiramisu eller Haxchi stöds inte.

Förutsättningar

  • Wii U kör Aroma med Coldboot aktiverad.
  • SD-kortläsare eller FTP-anslutning till konsolen.
  • Pretendo Network ID (PNID).
Steg 2

Ladda ner Inkay Switcher

Ladda ner programmet Inkay Switcher för att växla mellan serverreläer på konsolen.

Inkay Switcher (.wuhb)

Wii U Aroma Applikation

Ladda ned Release (.wuhb)
Ladda ner revivetendo_installer.wuhb från avsnittet Tillgångar på GitHub.

Placering av SD-kort

Kopiera revivetendo_installer.wuhb till /wiiu/apps/ katalogen på ditt SD-kort:

Katalogsökväg 
sd:/wiiu/apps/revivetendo_installer.wuhb

När du sätter tillbaka SD-kortet och startar din Wii U, visas ikonen Revivetendo Installer på din HOME-meny.

Revivetendo Installer application tile (Rv Installer) på din Wii U HOME Meny.
Steg 3

Installera det anpassade reläet

Konfigurera din konsol till rutten Wii U Chat till Nicos server.

  1. Öppna Inkay Switcher: Starta Revivetendo Installer från din Wii U HOME meny.
  2. Välj anpassat relä: Välj Revivetendo. (För att återvända till standard Pretendo senare, välj Pretendo istället).
    Välj "Revivetendo" från växlarmenyn.
  3. Installera och starta om: Välj din miljö, tryck på A för att installera, tryck sedan på B för att starta om.
    Bekräftelsefråga visas innan omstart.

Verifikationskontroll

Efter omstart, kolla den övre vänstra bannern på HOME-menyn. Det bör säga: Använda Pretendo Network (Revivetendo).

Insticksmeny i spel

Öppna Plugin-menyn var som helst på din Wii U genom att trycka på L + + - eller +. Välj Inkay (Revivetendo) för att hantera anslutningsinställningar eller återställa WaraWara Plaza.

Juxtaposition Miiverse

Revivetendo är också värd för en anpassad instans av Juxtaposition för speciella Miiverse samhällen.

Åtkomst till webben

Bläddra bland handskrivna inlägg, skärmdumpar och spel/app-gemenskaper direkt från valfri webbläsare.

Starta Revivetendo Juxt

WaraWara Plaza

Mii-avatarer, ritningar och populära inlägg laddas automatiskt på din TV-skärm när du startar Aroma.

Separera konton

Dina inlägg, gemenskaper och anhängare på Pretendos och Revivetendos servrar förblir åtskilda över plattformar.

Förutsättningar

  • En homebrew-kapabel 3DS (riktig hårdvara) eller Azahar.
  • En CIA-installatör på verklig hårdvara om du inte redan har en (FBI är standardvalet).

  • En fungerande internetanslutning på konsolen.
  • För Azahar endast: Azahar URL Redirection File release (http_hle_replace_rules.txt) från samma utgåvor sida.

Installationssteg: Real Hardware

Följ dessa steg för att ansluta din fysiska 3DS/2DS till reläet.

Steg 1

Installera Nimbus

Ladda ner nimbus.cia från den senaste app-v* utgåvan och lägg den på ditt SD-kort. Använda FBI (eller din CIA installer av val), installera det.

Steg 2

Välj det anpassade reläet

Öppna Nimbus från hemmenyn och tryck på VÄLJ för att öppna nätverksskärmen.

Välj Revivetendo med UP/DOWN knapparna och tryck på A. Nimbus kommer att ladda ner de nyaste patcharna, installera dem och be dig att trycka på Start för att starta om.

Inställningar för nätverkets skärm

  • Pretendo — lagret Pretendo patchar.
  • Roseverse — Pretendo med Roseverse konto, HTTP och Miiverse fläckar.
  • Revivetendo — vårt fullständiga nätverk. Ersätter allt inklusive eShop/Badge Arcade patchar som bara finns här, routing vad vi värd för oss och allt annat till Pretendo.
Steg 3

Testa Miiverse

Öppna Miiverse från din hemmeny för att testa. Om det laddar framgångsrikt, är du bra att gå! Verklig hårdvara plockar upp omdirigeringarna automatiskt när Nimbus är lappad.

Installationssteg: Azahar (Emulator)

Azahars emulerade SD-kort är mappen sdmc i din valda Azahar lagringsmapp.

Steg 1

Installera Nimbus

Ladda ned nimbus.cia från den senaste app-v* utgåvan. I Azahar, installera det på samma sätt som du skulle någon CIA (File → Installera CIA).

Steg 2

Aktivera LLE-moduler

Aktivera "Aktivera obligatoriska LLE-moduler för att använda onlinetjänster" -alternativet i Azahar (Emulation → Configure → System). Utan detta fungerar inte online-funktionerna.

Steg 3

Tillämpa Patchar i Nimbus

Starta hemmenyn, kör Nimbus, tryck på VÄLJ, välj Revivetendo och tillämpa patcharna precis som på riktig hårdvara.

Steg 4

Ställ in URL-omdirigering

Ladda ner http_hle_replace_rules.txt från Azahar URL Omdirigeringsfil och placera den på:

<your Azahar storage folder>/sysdata/http_hle_replace_rules.txt

Ingen emulatorinställning behöver växlas. Azahar laddar filen automatiskt vid nästa lansering.

Steg 5

Testa och verifiera

Starta Miiverse att testa. Du kan kolla Azahars loggfil för en rad som:

Service.HTTP <Warning>... Tillämpa:2258: regel "<pattern>" har ersatt URL "<original>" till "<new>"

Om du ser att med en förnuftig ersättare, är omdirigeringen levande.

Vad omdirigeras?

Båda vägarna omdirigerar samma uppsättning riktiga Nintendo/Pretendo värdnamn till våra egna servrar:

  • Miiverse
  • BOSS/SpotPass
  • connecttest & kontoinloggning
  • Swap Doodle's NASC login + HPP relay
  • Nintendo Badge Arcades eShop-stil "buy plays" flöde (pekade på vår egen shop backend istället för Nintendos riktiga servrar).

Obs: 3DS Vänner och NASC för andra titlar är medvetet vänster pekar på det verkliga Pretendo Network, orörda.
