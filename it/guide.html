Revivetendo Relè Rete — Guida All'Installazione

Seleziona la tua console per iniziare con la Rete Relè Revivetendo.

Passi Di Installazione

Segui questi quattro passaggi per collegare la console al relè.

Fase 1

Controlla La Tua Impostazione Homebrew

La tua Wii U deve essere in esecuzione con Aroma Homebrew Environment con Coldboot abilitato.

Perché è richiesto Coldboot

Coldboot avvia Inkay quando la console si accende in modo che i servizi SpotPass possano connettersi correttamente. Metodi più vecchi come Tiramisu o Haxchi non sono supportati.

Prerequisiti

  • Wii U che esegue Aroma con Coldboot abilitato.
  • Lettore di schede SD o connessione FTP alla console.
  • Pretendo Network ID (PNID).
Fase 2

Scarica Interruttore Inkay

Scarica l'applicazione Interruttore Inkay per passare da un relè server alla tua console.

Interruttore Inkay (.wuhb)

Applicazione Wii U Aroma

Scarica Rilascio (.wuhb)
Scarica revivetendo_installer.wuhb dalla sezione Risorse su GitHub.

Posizionamento Scheda Sd

Copia revivetendo_installer.wuhb nella directory /wiiu/apps/ sulla tua scheda SD:

Percorso Directory 
sd:/wiiu/apps/revivetendo_installer.wuhb

Quando rimetti indietro la scheda SD e avvii la tua Wii U, l'icona Revivetendo Installer apparirà sul tuo menu HOME .

Revivetendo Installer Application tile (Rv Installer) sul tuo Wii U HOME Menu.
Fase 3

Installa il Relè Personalizzato

Configura la console per indirizzare la Wii U Chat verso il server di Nico.

  1. Open Inkay Switcher: Avvia Revivetendo Installer dal tuo menu Wii U HOME
  2. Select Custom Relay: Choose Revivetendo. (Per tornare a Pretendo standard più tardi, selezionare Pretendo invece).
    Seleziona "Revivetendo" dal menu di commutazione.
  3. Installazione e riavvio: Seleziona il tuo ambiente, premi A per installare, quindi premi B per riavviare.
    prompt di conferma mostrato prima del riavvio.

Verifica

Dopo il riavvio, controllare il banner in alto a sinistra nel menu HOME Dovrebbe dire: Usando Pretendo Network (Revivetendo).

Menu Plugin In-Game

Apri il menu Plugin ovunque sulla tua Wii U premendo L + + - o +. Seleziona Inkay (Revivetendo) per gestire le impostazioni di connessione o resettare la tua Plaza WaraWara.

Miiverso Della Juxtaposition

Revivetendo ospita anche un'istanza personalizzata di Juxtaposition per speciali comunità Miiverse.

Accesso Web

Sfoglia i post scritti a mano, gli screenshot e le community di gioco/app direttamente da qualsiasi browser.

Lancia Revivetendo Juxt

WaraWara Plaza

Mii avatar, disegni, e popolari post caricano automaticamente sullo schermo TV quando si avvia Aroma.

Domande Frequenti

Proprio come i server ufficiali, la nostra rete deve verificare la console per permetterti di giocare online. Quando ti connetti, la console invia automaticamente il numero di serie, l'ID/certificato del dispositivo e un hash della password per accedere. Utilizziamo questi dati tecnici solo per autenticare il tuo dispositivo e garantire che i servizi funzionino senza intoppi!

Prerequisiti

  • Un 3DS homebrew (hardware reale) o Azahar.
  • Un installatore CIA su hardware reale se non ne hai già uno (FBI è la scelta standard).
  • The latest Nimbus app release (nimbus.cia, tag app-v*) from nimbus-nico_christmann releases. Usa questa piuttosto che quella di upstream: le patch vengono scaricate automaticamente dall'app.
  • Una connessione internet funzionante sulla console.
  • Solo per Azahar: la versione Azahar URL Redirection File (http_hle_replace_rules.txt) dalla stessa pagina delle releases.

Passi Di Installazione: Hardware Reale

Segui questi passaggi per collegare il tuo 3DS/2DS fisico al relè.

Fase 1

Installa Nimbus

Scarica nimbus.cia dall'ultima versione di app-v* e mettila sulla tua scheda SD. Utilizzando FBI (o il vostro installatore CIA di scelta), installarlo.

Fase 2

Seleziona il Relè Personalizzato

Apri Nimbus dal menu Home e premi SELECT per aprire la schermata di rete.

Scegli Revivetendo con i pulsanti UP/DOWN e premi A. Nimbus scaricherà le patch più recenti, le installerà e ti chiederà di premere Start per riavviare.

Opzioni Schermo Di Rete

  • Pretendo — le patch Pretendo a magazzino.
  • Roseverse — Pretendo con Roseverse's Account, HTTP e Miiverse patch.
  • Revivetendo — la nostra rete completa. Sostituisce tutto compreso eShop / Badge Arcade patch che esistono solo qui, instradando quello che ospitiamo a noi e tutto il resto a Pretendo.
Fase 3

Prova Miiverso

Apri Miiverso dal tuo Menu Home per provare. Se carica con successo, sei bravo da andare! L'hardware reale raccoglie automaticamente i reindirizzamenti una volta che Nimbus è patchato.

Passi Di Installazione: Azahar (Emulator)

La scheda SD emulata di Azahar è la cartella sdmc all'interno della cartella di archiviazione Azahar scelta.

Fase 1

Installa Nimbus

Scarica nimbus.cia dall'ultima versione di app-v*. In Azahar, installarlo allo stesso modo che si desidera qualsiasi CIA (File → Installa CIA).

Fase 2

Abilita Moduli LLE

Abilita l'opzione "Abilita i moduli LLE richiesti per utilizzare i servizi online" in Azahar (Emulazione → Configura → Sistema). Senza questo, le funzionalità online non funzioneranno.

Fase 3

Applica patch in Nimbus

Avviare il menu Home, eseguire Nimbus, premere SELECT, scegliere Revivetendo e applicare le patch proprio come su hardware reale.

Fase 4

Reindirizzamento URL Di Configurazione

Scarica http_hle_replace_rules.txt dal rilascio Azahar URL Redirection File e inseriscilo a:

<your Azahar storage folder>/sysdata/http_hle_replace_rules.txt

Nessuna impostazione di emulatore deve essere attivata. Azahar carica automaticamente questo file al prossimo lancio.

Fase 5

Prova e verifica

Avvia Miiverso per provare. Puoi controllare il file di registro di Azahar per una riga come:

Service.HTTP <Warning>... Applicabile:2258: regola "<pattern>" ha sostituito URL "<original>" " "<new>"

Se vedi che con una sana sostituzione, il reindirizzamento è dal vivo.

Che cosa viene reindirizzato?

Entrambi i percorsi reindirizzano lo stesso insieme di nomi host Nintendo/Pretendo reali ai nostri server:

  • Miiverso
  • BOSS/SpotPass
  • accesso & account conntest
  • Swap Doodle's NASC login + HPP relay
  • Nintendo Badge Arcade's eShop-style "buy plays" flusso (puntato sul nostro backend negozio invece dei veri server di Nintendo).

Note: 3DS Friends and NASC for other titles are deliberatamente left point at the real Pretendo Network, unouched.
