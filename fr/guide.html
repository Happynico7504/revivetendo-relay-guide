Revivetendo Relay Network — Guide d'installation

Sélectionnez votre console pour commencer avec le Revivetendo Relay Network.

Étapes d'installation

Suivez ces quatre étapes pour connecter votre console au relais.

Étape 1

Vérifiez votre installation d'Homebrew

Votre Wii U doit exécuter l'environnement Aroma Homebrew Environment avec Coldboot activé.

Pourquoi Coldboot est requis

Coldboot démarre l'encre lorsque la console s'allume pour que les services SpotPass puissent se connecter correctement. Les anciennes méthodes comme Tiramisu ou Haxchi ne sont pas supportées.

Pré-requis

  • Wii U en cours d'exécution Aroma avec Coldboot activé.
  • Lecteur de carte SD ou connexion FTP à votre console.
  • Pretendo Network ID (PNID).
Étape 2

Télécharger le commutateur d'encre

Téléchargez l'application Inkay Switcher pour basculer entre les relais du serveur sur votre console.

Interrupteur d'encre (.wuhb)

Application Wii U Aroma

Télécharger la version (.wuhb)
Download revivetendo_installer.wuhb from the Assets section on GitHub.

Placement de la carte SD

Copiez revivetendo_installer.wuhb dans le répertoire /wiiu/apps/ de votre carte SD :

Chemin de Répertoire 
sd:/wiiu/apps/revivetendo_installer.wuhb

Lorsque vous remettez la carte SD et démarrez votre Wii U, l'icône d'installation de Revivetendo apparaîtra sur votre menu Accueil.

Revivetendo Installer application tile (Rv Installer) on your Wii U HOME Menu.
Étape 3

Installer le Relais Personnalisé

Configurez votre console pour acheminer le chat Wii U vers le serveur de Nico.

  1. Open Inkay Switcher: Launch Revivetendo Installer from your Wii U HOME Menu.
  2. Sélectionnez un Relais Personnalisé : Choisissez Revivetendo. (To return to standard Pretendo later, select Pretendo instead).
    Sélectionnez "Revivetendo" dans le menu du sélecteur.
  3. Installer et Redémarrer : Sélectionnez votre environnement, appuyez sur A pour installer, puis appuyez sur B pour redémarrer.
    Demande de confirmation affichée avant de redémarrer.

Vérification

Après le redémarrage, vérifiez la bannière en haut à gauche sur le menu Accueil. Il devrait dire : en utilisant Pretendo Network (Revivetendo).

Menu des plugins en jeu

Ouvrez le menu des plugins n'importe où sur votre Wii U en appuyant sur L + + - ou +. Sélectionnez Inkay (Revivetendo) pour gérer les paramètres de connexion ou réinitialiser votre place WaraWara.

Miiverse de Juxtaposition

Revivetendo héberge également une instance personnalisée de Juxtaposition pour les communautés Miiverse spéciales.

Accès Web

Parcourez les publications manuscrites, les captures d'écran et les communautés de jeux/applications directement à partir de n'importe quel navigateur.

Place WaraWara

Les avatars Mii, les dessins et les publications populaires se chargent automatiquement sur l'écran de votre téléviseur lors du démarrage d'Aroma.

Comptes séparés

Foire aux questions

Réponses rapides aux questions les plus fréquemment posées sur le relais.

Les jeux qui ne sont pas relayés passent directement par le réseau officiel de Pretendo (pretendo.network). Vous n'avez pas besoin de changer de réseau pour jouer aux jeux Pretendo normaux.

Ouvrez le menu du plugin (L + + - ou +), sélectionnez Encre (Reviveten), et choisissez Reset WaraWara Plaza.

Tout comme les serveurs officiels, notre réseau doit vérifier votre console pour vous permettre de jouer en ligne. Lorsque vous vous connectez, votre console envoie automatiquement son numéro de série, son ID/certificat de périphérique et un hachage de mot de passe pour vous connecter. Nous n'utilisons ces données techniques que pour authentifier votre appareil et assurer le bon fonctionnement des services !

Pré-requis

  • Une 3DS (matériel réel) ou Azahar.
  • A CIA installer on real hardware if you don't already have one (FBI is the standard choice).
  • La dernière version de l'app Nimbus (nimbus.cia, tag app-v*) de nimbus-nico_christmann sort. Utilisez celui-ci plutôt que celui en amont : les patchs sont téléchargés automatiquement par l'application.
  • Une connexion internet fonctionnelle sur la console.
  • Pour Azahar seulement : la version Azahar URL Redirection File (http_hle_replace_rules.txt) de la même page de publications.

Étapes d'installation : Matériel réel

Suivez ces étapes pour connecter votre 3DS/2DS physique au relais.

Étape 1

Installer Nimbus

Téléchargez nimbus.cia depuis la dernière version app-v* et mettez-la sur votre carte SD. En utilisant FBI (ou votre installateur CIA de choix), installez-le.

Étape 2

Sélectionnez le Relais Personnalisé

Ouvrez Nimbus à partir du Menu Home et appuyez sur SELECT pour ouvrir l'écran réseau.

Choisissez Revivetendo avec les boutons UP/DOWN et appuyez sur A. Nimbus téléchargera les rustines les plus récentes, les installera et vous demandera d'appuyer sur Démarrer pour redémarrer.

Options de l'écran de réseau

  • Pretendo — les patchs de Pretendo par défaut.
  • Roseverse – Pretendo with Roseverse's Account, HTTP, and Miiverse patches.
  • Revivetendo — notre réseau complet. Remplace tout, y compris les patchs eShop/Badge Arcade qui n'existent qu'ici, routant ce que nous hébergeons et tout le reste à Pretendo.
Étape 3

Tester Miiverse

Ouvrez Miiverse à partir de votre menu d'accueil pour tester. Si elle se charge avec succès, vous êtes prêt à partir ! Le matériel réel récupère automatiquement les redirections une fois que Nimbus est patché.

Étapes d'installation : Azahar (Emulateur)

La carte SD émulée d'Azahar est le dossier sdmc dans le dossier de stockage Azahar que vous avez choisi.

Étape 1

Installer Nimbus

Téléchargez nimbus.cia depuis la dernière version app-v*. Dans Azahar, installez-le de la même façon que vous n'importe quel CIA (File → Installer CIA).

Étape 2

Activer les modules LLE

Activez l'option "Activer les modules LLE requis pour utiliser les services en ligne" dans Azahar (Emulation → Configurer → Système). Sans cela, les fonctionnalités en ligne ne fonctionneront pas.

Étape 3

Appliquer les correctifs dans Nimbus

Démarrez le menu d'accueil, exécutez Nimbus, appuyez sur SELECT, choisissez Revivetendo et appliquez les correctifs comme sur le matériel réel.

Étape 4

Configuration de la redirection d'URL

Téléchargez http_hle_replace_rules.txt depuis la version Azahar du fichier de redirection d'URL et placez-la dans:

<your Azahar storage folder>/sysdata/http_hle_replace_rules.txt

Aucun paramètre d'émulateur ne doit être basculé. Azahar charge automatiquement ce fichier au prochain lancement.

Étape 5

Tester et vérifier

Lancez Miiverse pour tester. Vous pouvez vérifier le fichier journal d'Azahar pour une ligne comme :

Service.HTTP <Warning>... Appliquer:2258: la règle "<pattern>" a remplacé l'URL "<original>" à "<new>

Si vous voyez cela avec un remplacement sain, la redirection est en direct.

Qu'est-ce qui est redirigé ?

Les deux chemins redirigent le même ensemble de vrais noms d'hôtes Nintendo/Pretendo vers nos propres serveurs :

  • Miiverse
  • BOSS/SpotPass
  • connexion et connexion au compte
  • Swap Doodle's NASC login + HPP relay
  • Le flux « acheter des jeux » de style eShop de Nintendo Badge Arcade (pointé sur notre propre backend de boutique au lieu des vrais serveurs de Nintendo).

Note : Les Amis 3DS et les NASC pour autres sont délibérément à gauche pointant vers le vrai réseau Pretendo, intacte.
