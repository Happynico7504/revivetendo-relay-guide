Revivetendo Relay Network — Setup Guide

Vælg din konsol for at komme i gang med Revivetendo Relay Network.

Installationstrin

Følg disse fire trin for at forbinde din konsol til relæet.

Trin 1

Tjek Din Homebrew Opsætning

Din Wii U skal køre Aroma Homebrew Environment med Coldboot aktiveret.

Hvorfor Coldboot er påkrævet

Coldboot starter Inkay når konsollen aktiverer på så SpotPass tjenester kan forbinde korrekt. Ældre metoder som Tiramisu eller Haxchi understøttes ikke.

Forudsætninger

  • Wii U kører Aroma med Coldboot aktiveret.
  • SD-kortlæser eller FTP-forbindelse til din konsol.
  • Pretendo Netværks-ID (PNID).
Trin 2

Download Inkay Skifter

Download Inkay Switcher programmet til at skifte mellem server relæer på din konsol.

Inkay Switcher (.wuhb)

Wii U Aroma Application

Hent udgivelse (.wuhb)
Download revivetendo_installer.wuhb fra Assets sektionen på GitHub.

Placering Af SD-kort

Kopier revivetendo_installer.wuhb til mappen /wiiu/apps/ på dit SD-kort:

Mappevej 
sd:/wiiu/apps/revivetendo_installer.wuhb

Når du sætter SD-kortet tilbage og starter din Wii U, vises Revivetendo Installer ikonet på din HOME Menu.

Revivetendo Installer applikations-flise (Rv Installer) på din Wii U HOME Menu.
Trin 3

Installer det Tilpassede Relæ

Konfigurer din konsol til at rute Wii U Chat til Nicos server.

  1. Åbn Inkay Switcher: Start Revivetendo Installer fra din Wii U HOME Menu.
  2. Vælg Brugerdefineret Relay: Vælg Revivetendo. (For at vende tilbage til standard Pretendo senere, vælg Pretendo i stedet).
    Vælg "Revivetendo" i menuen switcher.
  3. Installer og genstart: Vælg dit miljø, tryk på A for at installere, og tryk derefter på B for at genstarte.
    Bekræftelsesprompt vist før genstart.

Kontrol Af Verifikation

Efter genstart skal du tjekke det øverste venstre banner på HOME Menu. Det bør sige: Brug Pretendo Network (Revivetendo).

Plugin- Menuen

Åbn Plugin Menu hvor som helst på din Wii U ved at trykke på L + + - eller +. Vælg Inkay (Revivetendo) for at administrere forbindelsesindstillinger eller nulstille din WaraWara Plaza.

Hurtige svar på almindelige spørgsmål om relæet.

Åbn Plugin Menu (L + + - eller +), Vælg Inkay (Revivetendo), og vælg Nulstil WaraWara Plaza.

Ja. Men at downloade indhold fra GitHub for ofte på kort tid kan udløse en midlertidig GitHub sats grænse. - I så fald skal du vente på, at grænsen udløber, før du kan skifte igen.

Ligesom officielle servere skal vores netværk bekræfte din konsol for at lade dig spille online. Forudsætninger

  • Et hjemmebrygget 3DS (real hardware) eller Azahar.
  • En CIA installatør på ægte hardware hvis du ikke allerede har en (FBI er standardvalget).
  • Den seneste Nimbus app version (nimbus.cia, tag app-v*) fra nimbus-nico_christmann releases. Brug denne i stedet for upstream's: Fejlrettelserne downloades automatisk af appen.
  • En fungerende internetforbindelse på konsollen.
  • Kun for Azahar: udgivelsen Azahar URL Redirection File (http_hle_replace_rules.txt) fra den samme udgivelsesside.

Installationstrin: Rigtig Hardware

Følg disse trin for at forbinde din fysiske 3DS/2DS til relæet.

Trin 1

Installer Nimbus

Download nimbus.cia fra den seneste app-v* udgivelse og placer den på dit SD-kort. Brug FBI (eller din CIA installatør af valg), installere det.

Trin 2

Vælg det brugerdefinerede relæ

Åbn Nimbus fra startmenuen, og tryk på SELECT for at åbne netværksskærmen.

Vælg Revivetendo med UP/DOWN knapperne og tryk på A. Nimbus vil hente de nyeste patches, installere dem, og bede dig om at trykke på Start for at genstarte.

Indstillinger For Netværksskærm

  • Pretendo — lager Pretendo patches.
  • Roseverse — Pretendo med Roseverse's Account, HTTP og Miiverse patches.
  • Revivetendo — vores fulde netværk. Erstatter alt herunder eShop / Badge Arcade patches, der kun findes her, routing hvad vi vært for os og alt andet at Pretendo.
Trin 3

Test Miiverse

Åbn Miiverse fra din Hjemmenu for at teste. Hvis det indlæser med succes, er du god til at gå! Real hardware opfanger omdirigeringer automatisk, når Nimbus er lappet.

Installationstrin: Azahar (Emulator)

Azahar's emulerede SD-kort er mappen sdmc i din valgte Azahar lagermappe.

Trin 1

Installer Nimbus

Download nimbus.cia fra den seneste app-v* udgivelse. I Azahar, installere det på samme måde ville du enhver CIA (Fil → Installer CIA).

Trin 2

Aktiver LLE Modules

Aktiver indstillingen "Aktiver krævede LLE-moduler for at bruge online-tjenester" i Azahar (Emulation → Konfigurer → System). Uden dette vil onlinefunktioner ikke virke.

Trin 3

Anvend rettelser i Nimbus

Boot hjemmemenuen, kør Nimbus, tryk på SELECT, vælg Revivetendo og anvend patches ligesom på ægte hardware.

Trin 4

Opsæt Url Omdirigering

Download http_hle_replace_rules.txt fra Azahar URL Redirection File udgivelsen og placer den på:

<your Azahar storage folder>/sysdata/http_hle_replace_rules.txt

Ingen emulator indstilling skal skiftes. Azahar indlæser denne fil automatisk ved næste start.

Trin 5

Test og Verificér

Start Miiverse til test. Du kan tjekke Azahars logfil for en linje som:

Service.HTTP <Warning>... Anvende:2258: regel "<pattern>" har erstattet URL "<original>" til "<new>"

Hvis du ser, at med en sund udskiftning, omdirigering er levende.

Hvad bliver omdirigeret?

Begge stier omdirigere det samme sæt af reelle Nintendo/Pretendo værtsnavne til vores egne servere:

  • Miiverse
  • BOSS/SpotPass
  • conntest & konto login
  • Swap Doodle's NASC login + HPP relay
  • Nintendo Badge Arcades eShop-stil "buy plays" flow (pegede på vores egen butik backend i stedet for Nintendos virkelige servere).

Note: 3DS Friends and NASC for other titler er bevidst tilbage peger på det rigtige Pretendo Network, uberørt.
