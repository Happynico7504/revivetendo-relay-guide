Πολιτική Απορρήτου

Πληροφορίες σχετικά με τα δεδομένα που επεξεργαζόμαστε και αποθηκεύουμε στο Δίκτυο Revivetendo Relay.

Πώς Συνδέει Το Revivetendo

Ακριβώς όπως και οι επίσημοι διακομιστές, το δίκτυό μας πρέπει να επαληθεύσει την κονσόλα σας για να σας αφήσει να παίξετε online. When you connect, your console automatically sends its serial number, device ID/certificate, and a password hash to log in.

Γιατί η κονσόλα μου στέλνει αυτό?

Αυτές οι πληροφορίες είναι αυστηρά τεχνικές και χρησιμοποιούνται μόνο για να κάνουν τη σύνδεσή σας να λειτουργήσει! Επειδή το Revivetendo Relay Network επιτρέπει στην homebrewed κονσόλα σας να συνδεθεί με προσαρμοσμένες υπηρεσίες, πρέπει να πιστοποιήσουμε τη συσκευή σας ακριβώς όπως κάνουν οι επίσημοι διακομιστές. Μας βοηθά να διατηρήσουμε το δίκτυο ασφαλές και σταθερό για όλους.

Τι ακριβώς χρειάζεται για να συνδεθεί?

  • Σειριακός αριθμός Κονσόλας: Βοηθά το δίκτυο να αναγνωρίσει τη συγκεκριμένη κονσόλα σας όταν συνδεθείτε.
  • Αναγνωριστικό συσκευής / Πιστοποιητικό: Μια τυπική απαίτηση για ασφαλή επικοινωνία, ώστε η κονσόλα σας να μπορεί να μιλήσει με ασφάλεια στο δίκτυο.
  • Κωδικός Hash: Χρησιμοποιείται για την ασφαλή σύνδεσή σας. Η κονσόλα σας αυτόματα ανακατεύει τον κωδικό σας σε ένα ασφαλές "hash" πριν από τη σύνδεση, έτσι ο πραγματικός σας κωδικός δεν αφήνει ποτέ την κονσόλα σας.

Είναι τα δεδομένα μου ασφαλή?

Απολύτως! Αυτά τα τεχνικά δεδομένα δεν πωλούνται ούτε μοιράζονται. Απλά υπάρχει για να κρατήσει την κονσόλα σας με ασφάλεια συνδεδεμένη και να εξασφαλίσει ότι το δίκτυο παραμένει σε λειτουργία για όλους.
