Guia de configuração Revivetendo Relay Network —

Selecione o seu console para começar com a Rede Revivetendo Relay Network.

Etapas de instalação

Siga estas quatro etapas para conectar o seu console a um relógio.

Passo 1

Verifique seu Homebrew Setup

Seu Wii U deve estar executando o Aroma Homebrew Environment com Coldboot ativado.

Por que Coldboot é Necessário

Coldboot inicia o Inkay quando o console ligar para que os serviços do SpotPass se conectem corretamente. Métodos mais antigos como Tiramisu ou Haxchi não são suportados.

Pré-requisitos

  • Wii U executando Aroma com Coldboot ativado.
  • Leitor de cartão SD ou conexão FTP ao seu console.
  • ID da rede pretendo (PNID).
Passo 2

Baixar interruptor Inkay

Baixe o aplicativo Inkay Switcher para alternar entre os servidores de relés no seu console.

Alternador de Inkay (.wuhb)

Aplicativo para Wii U Aroma

Baixar versão (.wuhb)
Baixar revivetendo_installer.wuhb da seção de Assets no GitHub.

Colocação do Cartão SD

Copiar revivetendo_installer.wuhb no diretório /wiiu/apps/ no seu cartão SD:

Caminho do diretório 
sd:/wiiu/apps/revivetendo_installer.wuhb

Quando você colocar o cartão SD de volta e iniciar seu Wii U, o ícone do Instalador Revivetendo aparecerá no seu Menu HOME.

tile de aplicação Revivetendo Installer (Rv Installer) no seu menu do Wii U HOME.
Etapa 3

Instalar o Relé Personalizado

Configure o seu console para rotear Chat do Wii U para o servidor do Nico.

  1. Open Inkay Switcher: Launch Revivetendo Installer from your Wii U HOME Menu.
  2. Selecione Relé Personalizado: Escolher Revivetendo. (Para retornar à Pretendo mais tarde, selecione Pretendo em vez disso).
    Selecione "Revivetendo" no menu do interruptor.
  3. UInstalar e Reiniciar: Selecione seu ambiente, pressione A para instalar, e então pressione B para reiniciar.
    Pergunta de confirmação exibida antes de reiniciar.

Verificação de Verificação

Após reiniciar, verifique o banner superior esquerdo no Menu HOME. Deve dizer: Usando Pretendo Network (Revivetendo).

Menu do Plugin In-Game

Abra o Menu de Plugin em qualquer lugar do seu Wii U pressionando L + + - ou +. Selecione Inkay (Revivetendo) para gerenciar as configurações de conexão ou redefinir a sua WaraWara Plaza.

Juxtaposition Miiverse

O Revivetendo também hospeda uma instância personalizada da Juxtaposition para comunidades Miiverse especiais.

Acesso Web

Perguntas Frequentes

Respostas rápidas a perguntas comuns sobre o retorno.

Jogos que não estão transmitidos passam diretamente para o Pretendo Network (pretendo.network). Você não precisa mudar de rede para jogar jogos de Pretendo normais.

Abra o Menu Plugin (L + + + - ou +), selecione Inkay (Revivetendo)e escolha Reset WaraWara Plaza.

Sim. No entanto, baixar conteúdo do GitHub muitas vezes em um curto período de tempo pode acionar um limite temporário de taxa do GitHub. - Neste caso, você tem que esperar o limite expirar para poder alternar novamente.

Assim como os servidores oficiais, nossa rede precisa verificar o seu console para permitir que você jogue online. Quando você se conectar, o console envia automaticamente seu número de série, ID do dispositivo, certificado e um hash de senha para entrar. Utilizamos apenas estes dados técnicos para autenticar seu dispositivo e garantir que os serviços funcionem corretamente!

Pré-requisitos

  • Um 3DS homebrew-able (hardware real) ou Azahar.
  • Um instalador da CIA em hardware real se você ainda não tiver um (FBI é a escolha padrão).
  • A última versão do Nimbus app (nimbus.cia, tag app-v*) da versão nimbus-nico_christmann lançamentos. Use esse aplicativo em vez de upstreams: as correções são baixadas automaticamente pelo aplicativo.
  • Uma conexão à internet funcional no console.
  • Apenas para Azahar: a liberação Azahar de Redirecionamento de URL (http_hle_replace_rules.txt) da mesma página de lançamentos.

Etapas de instalação: Hardware Real

Siga estas etapas para conectar seu 3DS/2DS físico ao rely.

Passo 1

Instalar Nimbus

Baixe o nimbus.cia do último lançamento app-v* e coloque-o no seu cartão SD. Usando o FBI (ou seu instalador da CIA de escolha), instale-o.

Passo 2

Selecione o Relé Personalizado

Abra o Nimbus no Menu Inicial e pressione SELECT para abrir a tela de rede.

Escolha Revivetendo com os botões UP/DOWN e pressione A. O Nimbus irá baixar as atualizações mais recentes, instalá-las e solicitar que você pressione Start para reiniciar.

Opções de rede

  • Pretendo - os patches Pretendo de estoque.
  • Roseverse — Pretendo com a conta de Roseverse, HTTPS e correções Miiversas.
  • Revivetendo - nossa rede completa. Substitui tudo, incluindo os patches eShop/Badge Arcade que só existem aqui, roteando o que hospedamos para nós e tudo o mais para Pretendo.
Etapa 3

Testar Miiverse

Abra Miiverse de seu Menu Inicial para teste. Se a carga for carregada com sucesso, você está pronto para ir! O verdadeiro hardware pega os redirecionamentos automaticamente quando o Nimbus é retalhado.

Etapas de instalação: Azahar (Emulador)

O cartão SD emulado do Azaharformat@@1 é a pasta sdmc dentro da pasta de armazenamento do Azahar escolhida.

Passo 1

Instalar Nimbus

Baixe o nimbus.cia da versão mais recente do app-v*. Em Azahar, instale-o da mesma forma que você instalaria qualquer CIA (File → Instalar CIA).

Passo 2

Habilitar módulos LLE

Habilite o "Habilitar módulos LLE necessários para usar serviços online" opção no Azahar (Emulação → configurar → Sistema). Sem isso, os recursos online não funcionarão.

Etapa 3

Aplicar atualizações no Nimbus

Inicialize o Menu HOME, execute o Nimbus, pressione SELECT, escolha Revivetendo e aplique os patches como em um hardware real.

4° passo

Redirecionamento de URL configuração

Baixar http_hle_replace_rules.txt da liberação Azahar URL Redirection File e colocar em:

<your Azahar storage folder>/sysdata/http_hle_replace_rules.txt

Nenhuma configuração de emulador precisa ser alternada. O Azahar carrega esse arquivo automaticamente no próximo lançamento.

Passo 5

Testar e Verificar

Abra o Miiverse para o teste. Você pode verificar o arquivo de log do Azahar's para uma linha como:

Service.HTTP <Warning>... Aplicação:2258: regra "<pattern>" substituiu a URL "<original>" para "<new>"

Se virmos que com uma substituição sã o rediretor está vivo.

O que é redirecionado?

Ambos os caminhos redirecionam o mesmo conjunto de verdadeiros Nintendo/Pretendo hostnames para nossos próprios servidores:

  • Miívero
  • BOSS/SpotPass
  • teste & login da conta
  • Swap Doodle's NASC login + HPP relay
  • Fluxo "comprar jogas" do eShop, do Nintendo Badge Arcade, (apontado para o backend da nossa loja em vez dos servidores reais do Nintendo).

Nota: Amigos do 3DS e NASC para outros Títulos estão deliberadamente apontando para a rede Pretendo real, não tocado.
