Política de Privacidade

Informações sobre os dados que processamos e armazenamos na Rede Revivetendo Relay.

Como Revivetendo Conecta

Assim como os servidores oficiais, nossa rede precisa verificar o seu console para permitir que você jogue online. Quando você se conectar, o console envia automaticamente seu número número de série, ID/certificado do dispositivoe um hash de senha para entrar.

Por que meu console envia isto?

Esta informação é estritamente técnica e só é usada para fazer sua conexão funcionar! Porque a Revivetendo Relay Network permite que o seu homebrewed console conecte-se a serviços personalizados, temos que autenticar seu dispositivo exatamente da mesma forma que os servidores oficiais. Isso nos ajuda a manter a rede segura e estável para todos.

O que é exatamente necessário para iniciar sessão?

  • Número de Série de Consola: ajuda a rede a reconhecer o seu console específico quando você se conectar.
  • ID do dispositivo / Certificado: A exigência padrão para comunicação segura para que o console possa falar com segurança com a rede.
  • Senha Hash: Usado para iniciar sessão com segurança. Seu console confunde automaticamente sua senha em um "hash" seguro antes de se conectar, para que sua senha real nunca deixe seu console.

Meus dados estão seguros?

Absolutamente! Estes dados técnicos nunca são vendidos ou compartilhados. Ele existe simplesmente para manter seu console logado de forma segura e garantir que a rede permaneça ativa e funcionando para todos.
