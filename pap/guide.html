Revivetendo Relay Network — Setup Guide

Select your console to get started with the Revivetendo Relay Network.

Installation Steps

Follow these four steps to connect your console to the relay.

Step 1

Check Your Homebrew Setup

Your Wii U must be running the Aroma Homebrew Environment with Coldboot enabled.

Why Coldboot is Required

Coldboot starts Inkay when the console powers on so SpotPass services can connect properly. Older methods like Tiramisu or Haxchi are not supported.

Prerequisites

  • Wii U running Aroma with Coldboot enabled.
  • SD card reader or FTP connection to your console.
  • Pretendo Network ID (PNID).
Step 2

Download Inkay Switcher

Download the Inkay Switcher application to switch between server relays on your console.

Inkay Switcher (.wuhb)

Wii U Aroma Application

Download Release (.wuhb)
Download revivetendo_installer.wuhb from the Assets section on GitHub.

SD Card Placement

Copy revivetendo_installer.wuhb into the /wiiu/apps/ directory on your SD card:

Directory Path 
sd:/wiiu/apps/revivetendo_installer.wuhb

When you put the SD card back and start your Wii U, the Revivetendo Installer icon will appear on your HOME Menu.

Revivetendo Installer application tile (Rv Installer) on your Wii U HOME Menu.
Step 3

Install the Custom Relay

Configure your console to route Wii U Chat to Nico's server.

  1. Open Inkay Switcher: Launch Revivetendo Installer from your Wii U HOME Menu.
  2. Select Custom Relay: Choose Revivetendo. (To return to standard Pretendo later, select Pretendo instead).
    Select "Revivetendo" from the switcher menu.
  3. Install and Reboot: Select your environment, press A to install, then press B to reboot.
    Confirmation prompt shown before rebooting.

Verification Check

After rebooting, check the top-left banner on the HOME Menu. It should say: Using Pretendo Network (Revivetendo).

In-Game Plugin Menu

Open the Plugin Menu anywhere on your Wii U by pressing L + + - or +. Select Inkay (Revivetendo) to manage connection settings or reset your WaraWara Plaza.

Juxtaposition Miiverse

Prerequisites

  • A homebrew-capable 3DS (real hardware) or Azahar.
  • A CIA installer on real hardware if you don't already have one (FBI is the standard choice).
  • The latest Nimbus app release (nimbus.cia, tag app-v*) from nimbus-nico_christmann releases. Use this one rather than upstream's: the patches are downloaded automatically by the app.
  • A working internet connection on the console.
  • For Azahar only: the Azahar URL Redirection File release (http_hle_replace_rules.txt) from the same releases page.

Installation Steps: Real Hardware

Follow these steps to connect your physical 3DS/2DS to the relay.

Step 1

Install Nimbus

Download nimbus.cia from the latest app-v* release and put it on your SD card. Using FBI (or your CIA installer of choice), install it.

Step 2

Select the Custom Relay

Open Nimbus from the Home Menu and press SELECT to open the network screen.

Choose Revivetendo with the UP/DOWN buttons and press A. Nimbus will download the newest patches, install them, and ask you to press Start to reboot.

Network Screen Options

  • Pretendo — the stock Pretendo patches.
  • Roseverse — Pretendo with Roseverse's Account, HTTP, and Miiverse patches.
  • Revivetendo — our full network. Replaces everything including eShop/Badge Arcade patches that only exist here, routing what we host to us and everything else to Pretendo.
Step 3

Test Miiverse

Open Miiverse from your Home Menu to test. If it loads successfully, you're good to go! Real hardware picks up the redirects automatically once Nimbus is patched.

Installation Steps: Azahar (Emulator)

Azahar's emulated SD card is the sdmc folder inside your chosen Azahar storage folder.

Step 1

Install Nimbus

Download nimbus.cia from the latest app-v* release. In Azahar, install it the same way you would any CIA (File → Install CIA).

Step 2

Enable LLE Modules

Enable the "Enable required LLE modules to use online services" option in Azahar (Emulation → Configure → System). Without this, online features won't work.

Step 3

Apply Patches in Nimbus

Boot the Home Menu, run Nimbus, press SELECT, choose Revivetendo and apply the patches just like on real hardware.

Step 4

Setup URL Redirection

Download http_hle_replace_rules.txt from the Azahar URL Redirection File release and place it at:

<your Azahar storage folder>/sysdata/http_hle_replace_rules.txt

No emulator setting needs to be toggled. Azahar loads this file automatically on the next launch.

Step 5

Test and Verify

Launch Miiverse to test. You can check Azahar's log file for a line like:

Service.HTTP <Warning> ... Apply:2258: rule "<pattern>" has replaced URL "<original>" to "<new>"

If you see that with a sane replacement, the redirect is live.

What is redirected?

Both paths redirect the same set of real Nintendo/Pretendo hostnames to our own servers:

  • Miiverse
  • BOSS/SpotPass
  • conntest & account login
  • Swap Doodle's NASC login + HPP relay
  • Nintendo Badge Arcade's eShop-style "buy plays" flow (pointed at our own shop backend instead of Nintendo's real servers).

Note: 3DS Friends and NASC for other titles are deliberately left pointing at the real Pretendo Network, untouched.
