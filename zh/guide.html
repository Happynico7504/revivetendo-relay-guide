重生中继网络 — 安装指南

选择您的控制台来从 Revivetendo 中继网络开始。

安装步骤

按照这四个步骤将您的控制台连接到继电器。

步骤1

检查您的自制程序设置

Your Wii U must be running the Aroma Homebrew Environment with Coldboot enabled.

为什么需要Coldboot

Coldboot 开启Inkay，当控制台的权限使SpotPass服务能够正常连接。不支持像Tiramisu或Haxchi这样的旧方法。

必备条件

  • Wii U 启用了 Coldboot 运行Aroma。
  • SD 卡读取器或 FTP 连接到您的控制台。
  • Pretendo Network ID(PNID)。
步骤2

下载Inkay 切换器

下载Inkay 切换程序以在您的控制台上的服务器继电器之间切换。

Inkay 切换器 (.wuhb)

Wii U Aroma 应用程序

下载版本(.wuhb)
从GitHub上的Assets部分下载revivetendo_installer.wuhb。

SD 卡位置

Copy revivetendo_installer.wuhb into the /wiiu/apps/ directory on your SD card:

目录路径 
sd/wiiu/apps/revivetendo_installer.wuhb

当你将SD卡放回并启动Wii U时，Revivetendo安装程序图标将出现在你的HOME菜单上。

Revivetendo Installer application tile (Rv Installer) on your Wii U HOME Menu.
步骤3

安装自定义继电器

配置您的控制台，将Wii U 聊天路由到Nico服务器。

  1. 打开Inkay Switcher: 从您的Wii U HOME 菜单启动Revivetendo Installer。
  2. 选择自定义继电器： 选择 Revivetendo (To return to standard Pretendo later, select Pretendo instead).
    Select "Revivetendo" from the switcher menu.
  3. 安装并重启： 选择您的环境，按 安装，然后按 B 重新启动。
    Confirmation prompt shown before rebooting.

验证检查

重启后，请检查HOME菜单上左上角的横幅。 It should say: Using Pretendo Network (Revivetendo).

游戏内插件菜单

在您的Wii U任意位置打开插件菜单，按 L + + - 或 +。选择 Inkay (Revivetendo) 管理连接设置或重置您的 WaraWara

安装步骤：实时硬件

按照这些步骤将您的实体3DS连接到继电器。

步骤1

安装 Nimbus

从最新的 app-v* 下载 nimbus.cia 并将其放在你的 SD 卡上。使用 FBI (或您的 CIA 安装程序)，安装它。

步骤2

选择自定义继电器

从主屏幕打开Nimbus并按 SELECT 打开网络屏幕。

Choose Revivetendo with the UP/DOWN buttons and press A. Nimbus将下载最新的补丁，安装它们，并请您按开始重新启动。

网络屏幕选项

  • Pretendo - 股票Pretendo 补丁。
  • Roseverse — Pretendo with Roseverse's Account, HTTP, and Miiverse 补丁。
  • Revivetendo — — 我们的完整网络。替换所有只存在于这里的eShop/Badge Arcade 补丁，将我们的东道主和所有其他东西转到比勒陀利亚。
步骤3

测试 Miiverse

从您的主菜单打开Miivers进行测试。如果它加载成功，你很好！真正的硬件在Nimbus被修补后自动向上拾取重定向。

安装步骤：Azahar (Emulator)

Azahar仿真的 SD 卡是您选择的 Azahar 存储文件夹内的 sdmc 文件夹。

步骤1

安装 Nimbus

从最新的 app-v* 版本下载 nimbus.cia 在 Azahar, 安装它的方式与任意CIA (文件-> 安装 CIA )相同。

步骤2

启用 LLE 模块

启用 "启用所需的LLE 模块来使用在线服务" 选项在 Azahar (Emulation → Configure → System)。没有这一点，在线功能将无法工作。

步骤3

在 Nimbus 中应用补丁

Boot the Home Menu, run Nimbus, press SELECT, choose Revivetendo and apply the patches just like on real hardware.

步骤4

设置 URL 重定向

Download http_hle_replace_rules.txt from the Azahar URL Redirection File release and place it at:

<your Azahar storage folder>/sysdata/http_hle_reples.txt

无需切换仿真器设置。 Azahar 在下次启动时自动加载此文件。

步骤5

测试和验证

启动Miivers来测试。您可以检查Azahar的日志文件，如：

HTTP <Warning>... Apply:2258: rule "<pattern>" 已替换 URL "<original>" 到 "<new>"

如果你看到这一点，用净化的替代方法进行重定向即可。

什么是重定向的？

两条路径都将同一组真实的Nintendo/retendo主机名重定向到我们自己的服务器：

  • 米沃斯
  • BOS/SpotPass
  • 竞赛和帐户登录
  • Swap Doodle's NASC login + HPP relay
  • Nintendo Badge Arcade的eShop风格“购买游戏”流程(在我们自己的商店后端，而不是Nintendo的真正服务器上)。

注意： 3DS朋友和 NASC 为 其他 标题被故意留下指向真正的Pretendo 网络，未触摸。
