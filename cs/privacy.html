Ochrana osobních údajů

Informace o údajích, které zpracováváme a ukládáme na Revivetendo Relay Network.

Jak se spojí výnosy

Stejně jako oficiální servery je třeba, aby naše síť ověřila svou konzolu, která vám umožní hrát online. Po připojení, vaše konzole automaticky odešle své sériové číslo, ID/certifikát zařízenía hash pro přihlášení.

Proč to moje konzole posílá?

Tyto informace jsou přísně technické a slouží pouze k tomu, aby vaše připojení fungovalo! Protože Revivetendo Relay Network umožňuje vašemu domovskému konzoli připojit se k vlastním službám, musíme ověřit vaše zařízení přesně stejně jako oficiální servery. Pomáhá nám udržet síť bezpečnou a stabilní pro všechny.

Co přesně je potřeba k přihlášení?

  • Pořadové číslo konzoly: Pomáhá síti rozpoznat vaši konkrétní konzoli při připojení.
  • ID zařízení / certifikát: Standardní požadavek pro zabezpečenou komunikaci, aby vaše konzole mohla bezpečně komunikovat se sítí.
  • Hash hesla: Používá se k bezpečnému přihlášení. Konzole automaticky skrývá vaše heslo do bezpečného "hash" před připojením, takže vaše skutečné heslo nikdy neopustí konzoli.

Jsou moje data bezpečná?

Rozhodně! Tyto technické údaje se nikdy neprodávají ani nesdílejí. Jednoduše existuje proto, aby vaše konzole byla bezpečně přihlášena a aby síť zůstala v provozu pro všechny.
